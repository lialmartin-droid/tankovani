# Moje tankování

Mobilní PWA pro evidenci tankování, výpočet skutečné spotřeby mezi plnými nádržemi a sledování nákladů.

## Funkce

- rychlé zadání litrů, ceny, tachometru a plné/částečné nádrže,
- automatický dopočet ceny za litr nebo celkové částky,
- přesná spotřeba včetně částečných tankování mezi plnými nádržemi,
- historie s úpravou a mazáním záznamů,
- výběr známých českých sítí čerpacích stanic,
- vývoj ceny za litr a srovnání průměrných cen podle stanice,
- souhrny a grafy spotřeby a měsíčních nákladů,
- světlý, tmavý nebo systémový vzhled,
- offline provoz a instalace na plochu,
- export zálohy JSON, obnova zálohy a export CSV.

## GitHub Pages

Obsah složky `dist` nahraj do kořene repozitáře. V GitHubu potom otevři **Settings → Pages**, zvol **Deploy from a branch**, větev **main** a složku **/(root)**.

Data zůstávají uložená jen v prohlížeči daného telefonu. Před změnou telefonu nebo smazáním dat Safari si v aplikaci stáhni zálohu.
